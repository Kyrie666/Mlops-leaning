## 临时写一些工作内容
项目:大模型助手
通过大模型应用开发，构造个人知识库助手，帮助公司内部优化工作流，提升信息获取效率，促进决策支持；核心是针对目前常用的大模型API进行底层封装，基于 Langchain 搭建了可切换模型的检索问答链，并实现 API 以及 Gradio 部署的个人轻量大模型应用。核心技术包括 LLM API 调用、向量数据库构建、检索问答链以及后端部署调用。后期，会切换开源模型；
整个过程包括如下操作：首先加载和读取知识库文档，对知识库文档进行分割，对分割后的知识库文本向量化并存入向量库建立索引；用户提出问题 Query，对问句 Query 向量化，在知识库文档向量中匹配出与问句 Query 向量最相似的 top k 个，匹配出的知识库文本文本作为上下文 Context 和问题⼀起添加到 prompt 中，提交给 LLM 生成回答 Answer。可以大致分为索引，检索和生成三个阶段。


项目：AOI机的模拟和阈值智能推荐
通过数据挖掘和模型训练，找到AOI对缺陷分类过程中，一些比较重要的特征，当AOI机分类器阈值设置不合理导致过高的过杀率和漏检时，通过智能搜索阈值以及AOI机的在线模拟，推荐出合适的阈值提供给生产使用，可以有效降低过杀和漏检，提升现场调机的效率。
技术栈：模型可视化，特征筛选，多次随机搜索近似多重循环，算法部署。
